# Sample Data Policy

No production or synthetic legal/Shariah corpus is copied into this directory.

Use approved test fixtures in a controlled tenant environment. Recommended fixture categories are:

- `AAOIFI_STANDARD`
- `FATWA`
- `INTERNAL_SHARIAH_POLICY`
- `APPROVED_CONTRACT_TEMPLATE`
- `REGULATORY_GUIDANCE`

When adding a fixture, document:

- Source authority.
- Jurisdiction and country node.
- Effective date.
- Review owner.
- Whether the fixture is global or project-specific.

Do not commit confidential documents, customer financial records, private contracts, credentials, or licensed material that the project is not authorised to redistribute.
